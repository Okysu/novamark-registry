# NovaMark Registry Official Example Registry

- [中文 README](README_CN.md)

## About

NovaMark is a markup language and cross-platform runtime engine designed for text-based games, interactive fiction, and visual novels.

Official project: https://github.com/Okysu/NovaMark

## What is this repository?

This repository is the official NovaMark example registry. It collects sample packages, demos, and registry metadata so the community can discover and reuse NovaMark content.

## Contributing

We welcome pull requests. If you have a package, demo, or registry entry to share, please submit a PR.

### How to contribute

1. Fork this repository.
2. Add your package or example to the registry format.
3. Create a pull request describing your submission.

## Notes

This is the official NovaMark example registry. Your PR helps grow the NovaMark ecosystem and makes it easier for everyone to find high-quality sample content.

# NovaMark Registry 官方示例 Registry

- [English README](README.md)

## 关于

NovaMark 是一个为文字游戏、互动小说和视觉小说设计的标记语言及跨平台运行时引擎。

官方项目：https://github.com/Okysu/NovaMark

## 这个仓库是什么？

这个仓库是 NovaMark 官方示例 registry，用于汇总示例包、演示内容和 registry 元数据，便于社区发现和复用 NovaMark 资源。

## 贡献指南

我们欢迎通过 PR 上传内容。如果你有包、演示或者 registry 条目想分享，请提交 PR。

### 如何贡献

1. Fork 本仓库。
2. 按 registry 格式添加你的包或示例。
3. 提交 PR 并说明你的内容。

## 说明

这是 NovaMark 官方示例 registry。你的 PR 将帮助 NovaMark 生态成长，并让所有人更容易找到优质示例内容。
